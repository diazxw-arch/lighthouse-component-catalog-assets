# LH01-0010 · 部屋と寝具の数量条件

Reusable React component: `RoomQuantityFilters`.

Controlled nullable bedroom/bed/bathroom quantities. Null means unspecified; plus changes it to one and minus changes one back to null. Max and disabled states prevent invalid actions. Native buttons, visible focus, live output and enlarged hit targets support keyboard and touch.

Initial preview contains only the requested component. App services, persistence, authentication and data access remain application-owned. No native/device or human acceptance is claimed.

Design: original reference governs icon anatomy and fine geometry, with selected Image Gen v1 governing the reviewed Japanese rendition. Meiryo with licensed Noto Sans JP fallback; preserve authored blue location shortcuts, green history action and selected histogram, and neutral quantity controls. Shared libraries/fonts remain under their original Apache/OFL licenses.

Verification and exact release evidence are recorded in the per-item QA and Owner A acceptance ledger. Shared FigCraft cleanup is deferred until all dependent siblings are replaced and exclusive native editing is supported.
