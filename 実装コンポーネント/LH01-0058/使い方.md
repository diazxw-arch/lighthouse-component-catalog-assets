# LH01-0058 · 料金を表示する地図ラベル

Reusable React component: MapPriceMarker.

One compact white price pill inside a transparent 44px native hit area, with a controlled selected state and a stable place-ID callback. The label is supplied by the caller. The recorded ¥ 18,000 example is not live price data, a conversion, or a per-night claim. No pin tail or invented map art.

The initial preview shows only this component. Honest disconnected-service feedback appears only after an action. Required Noto/source notices remain in an inert delivered template. Original and Image Gen history are preserved. Source checks, actual rendered acceptance, release and native/mock retirement are separate.
