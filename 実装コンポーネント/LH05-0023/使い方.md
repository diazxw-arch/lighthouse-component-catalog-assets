# AppearanceSettings usage

Import AppearanceSettings and AppearancePreferences from src/components/catalog/AppearanceSettings.
Pass controlled value, onChange and onClose. The consumer owns reader rendering, fontloading, persistence, permissions, navigation and dismissal.
Preferences: size in pixels; colorMode(device/light/dark); theme(basic/warm/paper); applyToDocuments; pageMode(scroll/curl/slide); font; bold.
Optional minSize/maxSize default12/32. disabled/busy suppress edits while close remains available. error/onRetry provide recovery. controls optionally associates inputs with a real consuming readerID.

The11fontkeys in APPEARANCE_FONT_OPTIONS are meiryo, mincho, system, noto-sans-jp, noto-serif-jp, biz-udpgothic, biz-udpmincho, zen-maru-gothic, zen-kaku-gothic-new, zen-old-mincho andyomogi. Exact family strings reuse the existing LayoutMaker registry. Consumers can call canonical useLayoutFonts for local registrykeys; map mincho to noto-serif-jp. The component does not silently change the font of its own control labels.

The owner requested a settings-only preview: no sample reader, PDF renderer, pagecurl animation or visible licenseUI. State stays in the preview consumer and all selected controls remain real. Dismissal focuses the compact reopenaction; keyboardreopening focuses the closeaction, with no automatic focussteal on initialload.

Icon assets are inert localSVGs. Solar CC-BY4, Iconoir MIT and the embedded fallbackfont OFL notice are preserved in appearance-icons/NOTICES.css and the final HTMLstylesheet legalcomment. Original app fonts/licenses remain in public/fonts/japanese.
