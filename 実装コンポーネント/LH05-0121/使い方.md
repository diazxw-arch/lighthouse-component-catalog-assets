# LH05-0121 — QuoteCollectionReader

Import QuoteCollectionReader from its catalog source and import reader-utility.css. The preview also imports reader-utility-font.css and reader-utility-preview.css; the latter is only the standalone demo canvas. Keep the bundled Noto Sans JP license and existing font assets when reusing the fallback. The component prefers Meiryo where available.

## Host contract

Pass collectionLabel, quoteLines, author and controlled bookmarked. Handle onBack, onCollection, onHelp, onAdd, onShare and onBookmark(nextValue). The component never persists a quote or opens a native share surface itself.

## States

An empty quote displays an explanation and disables share/bookmark. disabled leaves Back and Help available. Bookmark on/off is supplied by the caller.

## Reference geometry

At 390px: card8/58/374/626; quote20Bold/28 begins278; author12Regular/16 begins474. The decorative opening mark uses a serif face to retain the original curly anatomy. The composition is capped at 390px and fits320px. On wider viewports the demo centers the authored component. Original and Image Gen references are retained.
