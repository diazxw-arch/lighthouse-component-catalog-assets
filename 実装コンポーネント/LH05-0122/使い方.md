# LH05-0122 — ReaderContentsSheet

Import ReaderContentsSheet from its catalog source and import reader-utility.css. The preview also imports reader-utility-font.css and reader-utility-preview.css; the latter is only the standalone demo canvas. Keep the bundled Noto Sans JP license and existing font assets when reusing the fallback. The component prefers Meiryo where available.

## Host contract

Pass controlled open/onOpenChange, tab/onTabChange, chapters, currentChapterId and onChapter. tab is contents, highlights, notes or bookmarks. Supply host React panels for the last three tabs. React and existing @radix-ui/react-dialog and @radix-ui/react-tabs are required.

## States

busy disables chapter actions and shows loading above the list. error and optional onRetry appear above the list. Empty chapters explain the absence. disabled blocks content actions while Close remains available. The caller owns data fetching and navigation.

## Reference geometry

At 390px: twelve48px rows, four34px segmented tabs, close pill342x44 aroundy694 with14Regular/24 label. In a320x480 viewport the body scrolls and Close remains reachable. The composition is capped at 390px and fits320px. On wider viewports the demo centers the authored component. Original and Image Gen references are retained.
