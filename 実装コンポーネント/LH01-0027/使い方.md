# LH01-0027 · 一週間の営業時間表

Reusable React component: `OpeningHoursWeek`.

Controlled expanded/onExpandedChange keeps a seven-day table and suggested-edit callback. Original clock and upward chevron indicate the initially expanded state; collapse rotates the source chevron. Current Tuesday is an explicit fixture currentDayId, with bold label/time; no runtime date inference. Edit callback reports an unconnected destination without sending anything.

Native Meiryo with existing licensed Noto Sans JP fallback preserves role typography. Initial preview contains the actual assigned component only.
