options supply actual artwork and labels; selectedIds/onValueChange independently toggle each stable ID. The initial reference preview selects only flexible. Artwork remains in color on hover; no gray overlay hides the artwork or selection meaning.

No human/pixel-identity certification, backend persistence, physical-device acceptance or Maker integration is claimed. QA, catalog release, exact deployment and deferred native cleanup are separate acceptance gates.
