# LH01-0042 · 施設を示す地図ピン

Reusable React component: FacilityMapPin.

Editable native SVG keeps the broad rounded head, tapered tail, dark solid center and forest gradient. Selection is controlled through selected/onSelect; the host owns actual map coordinates and selection. The preview toggles only its local selection state. The selected pin has a white center; the unselected pin preserves the original dark center. This visible selection persists after pointer release and remains separate from neutral keyboard focus.

Source references and generated candidates are pinned separately. Initial preview shows only this component; action feedback appears after activation. Licensed source notices travel inside an inert HTML template. Actual visual comparison, mobile/tablet/desktop behavior, production deployment and native/mock retirement remain separate gates.
