# LH05-0024 — 書体と太字の設定

Controlled reusable two-row FontSettings card. Caller owns loading/applying fonts, reader rendering, persistence and errors. Source target: reviewed Image Gen v001, SHA256 41c776ac1d82db4d3079fd28732c7d1eb79590e9abbc5ab10325e10db0d20aaf. Original Speechify screenshot ca505ee0-0012-40b1-993b-075db533807d.jpg, SHA256 88e613a06d9b7299b64505ece8617250d63b80681066244a1c5fff1856f9cac0, crop [48,1967,1083,297]. Both were inspected; original controls govern anatomy, image governs Japanese copy and neutral finish.

Design: white 358×100 logical card, radius14, inset16 divider, regular14/24 labels, slate thin chevron, off54×30 switch with22px thumb inset4. Follows Apple Design through compact hierarchy, immediate native feedback and keyboard operation. No decorative motion. Narrow widths shrink without label overlap. Meiryo first in reusable source; portable preview embeds the already shipped Noto Sans fallback and its license. No screenshot is used for UI.

Direct corrections from LH05-0023 apply to these comparable unbranded controls: neutral gray hover/focus, no green/tints, eleven existing font choices, settings-only presentation. Reference off state stays off; active switch uses charcoal. No theme tiles are present. Native select and switch update typed controlled preferences; disabled/busy block edits and retry, error supplies a real callback. The component is an isolated catalog entry, not a claim of a new distinct design family.

Usage: import FontSettings and FontPreferences. Pass value {font,bold} and onChange. Optional disabled, busy, error, onRetry and controls (only a real reader ID). Font keys reuse APPEARANCE_FONT_OPTIONS. The consuming reader loads canonical app families; mincho maps to noto-serif-jp. This settings-only preview deliberately contains no reader or visible credit panels. Source/image history and shared FigCraft library remain preserved until delivered replacement and safe node retirement are proven.
