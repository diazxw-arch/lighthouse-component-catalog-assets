# LH05-0035 — 学習の道すじ

Reusable LearningPath. Latest reviewed v002 and original Duolingo screenshot were inspected. Four independent native lesson buttons plus a disabled reward chest, no mascot/counters/header/text decorations. Native buttons contain editable atomic SVG face/ring/glyph layers; the full interface is not an image or single SVG overlay. Inactive faces are pure white with fine neutral edges and gray extrusion/icons; current face has authored forest gradient, dark sidewall and segmented ring with uniform #1F6444 progress.

Original rounded star, microphone, camera depth and two-post chest/round lock geometry were reconstructed as editable palette contours from exact original regions, documented in course-icons/PATH-SOURCES.md. Simplification tolerance0.8source pixel, about0.26logical pixel at390wide. This is reconstructed utility geometry, not original editable vector or pixel-identical sampling. Layout follows the original source centers and optical offsets rather than generated drift, within390x426 frame. No protected photography or mascot is substituted.

Apple Design: direct native buttons, clear current/locked meaning, sufficient phone hit targets, neutral focus/hover stroke preserving meaningful fills, no decorative motion. No extra demo sections.

Usage: nodes have unique id/label/kind and normalized x/y coordinates in390x426 space, currentId, selectedId, completedSegments0–4 and onSelect. Availability defaults to current only; explicit available enables future nodes with stronger neutral glyph contrast. Consumer owns navigation/completion/progress and persistence. Preview only changes controlled selection, never advances actual progress or fabricates completion. Optional reward/onReward, disabled/busy, error/onRetry and controls link host behavior. Per-instance gradient/description IDs are isolated.

Import learning-path.css and original-path-glyphs.ts. Portable preview adds scoped existing OFL Noto fallback with complete license; individual sources require repository React and font dependencies. Native rendering/interaction/phone-tablet-desktop comparison completed. Independent review, release/catalog publication and supported cleanup are tracked separately. Generated review, source, agent QA, human acceptance and production are separate; original/Image Gen/native 第02集 node11 remain preserved.
