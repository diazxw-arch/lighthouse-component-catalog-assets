# LH01-0017 · 設備の図形付き選択グリッド

Reusable React component: `EquipmentSelectionGrid`.

selectedIds/onValueChange control six independent equipment options with distinct stable IDs, including free-parking and paid-parking. The initial two-column/three-row grid has no selected tile and no extra heading. Later selection uses a neutral slate boundary and gray surface; the reference does not establish a colored selected state.

All six glyphs use exact original-source crop pixels in original-equipment-grid.svg through ReferenceGlyph. The oven retains four knobs, washer retains its single dot/wave, and paid parking uses the source meter. The original source bytes are embedded unchanged; no substitute glyph paths are drawn.

Meiryo with existing licensed Noto Sans JP fallback; source14/24 regular labels and20/28 headings where present. Initial display contains only the requested component and its recorded states. Application services, persistence, auth and filter results remain application-owned. No physical-device, human, pixel-identity or Maker-integration claim. Rendered QA, catalog/production verification and native/mock cleanup are separate gates.
