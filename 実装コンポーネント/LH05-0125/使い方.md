# LH05-0125 — UnitRewindCard

Import UnitRewindCard from its catalog source and import reader-utility.css. The preview also imports reader-utility-font.css and reader-utility-preview.css; the latter is only the standalone demo canvas. Keep the bundled Noto Sans JP license and existing font assets when reusing the fallback. The component prefers Meiryo where available.

## Host contract

Pass heading, descriptionLines, actionLabel, artworkSrc and onStart. Supply the unchanged original artwork; the preview imports reader-utility-media/unit-rewind-character.png. Original reference media remains retained. The host processes navigation, progress and points.

## States

busy supplies a preparation label and blocks Start. disabled blocks Start. error is a separate alert. The supplied points wording is a request label and does not award points.
