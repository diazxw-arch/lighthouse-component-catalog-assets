# ReadingSettings usage

Import ReadingSettings and ReadingPreferences from src/components/catalog/ReadingSettings.
Importing the component also loads its scoped stylesheet.

Pass a controlled value containing font (standard/body), fontSize in pixels, theme (white/sepia/gray/black), and brightness from 0 to 100.
onChange receives the next full preferences value. The consumer applies it to its reader, saves it if appropriate, and handles permissions.
The preview demonstrates changes to genuine text, background and brightness.

Optional minSize/maxSize/sizeStep configure size boundaries. disabled and busy lock controls; busy announces loading. error and onRetry expose recovery. controls associates the UI with a reader element ID.
Each instance has its own radio group. Native buttons never submit an enclosing form.
