# LH05-0123 — ReadingBookUtilityHeader

Import ReadingBookUtilityHeader from its catalog source and import reader-utility.css. The preview also imports reader-utility-font.css and reader-utility-preview.css; the latter is only the standalone demo canvas. Keep the bundled Noto Sans JP license and existing font assets when reusing the fallback. The component prefers Meiryo where available.

## Host contract

Pass title, status, onBack, onDiscussion and onTool. ReadingBookTool is display, contents, highlights, notes or bookmarks. Implement the corresponding reader surfaces in the host.

## States

disabled disables discussion and the five tools while Back remains available. The preview empty-book message is host data. Headings wrap and push status/tools down when narrow.

## Reference geometry

At 390px: title20Regular at8, status12Regular at44; circles40px centered48/124/200/276/352 at98; labels12Regular at128. The default composition remains160px high. The composition is capped at 390px and fits320px. On wider viewports the demo centers the authored component. Original and Image Gen references are retained.
