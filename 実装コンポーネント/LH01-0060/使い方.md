# LH01-0060 · 地域と日程と人数を入力する検索フォーム

Reusable React component: DestinationSearchForm.

Compose the reviewed destination panel with two collapsed date/guest actions and clear/search footer. Query, options, dates, guest label and all actions are application-owned. Existing magnifier and Enter paths call the request handler directly after native validity and avoid implicit submission in the strict sandbox; the footer is also a native type=button action. Search green retains authored meaning with minimum 4.66:1 white-text contrast. No booking, geolocation or picker service is claimed. Reused anatomy is not counted as a new distinct design.

The initial preview shows only this component. Honest disconnected-service feedback appears only after an action. Required Noto/source notices remain in an inert delivered template. Original and Image Gen history are preserved. Source checks, actual rendered acceptance, release and native/mock retirement are separate.
