# LH01-0024 · 施設写真の横スクロール帯

Reusable React component: `FacilityPhotoStrip`.

Photos are unchanged byte-for-byte original crops in static SVG containers, not generated food approximations. HTML overlays only the Japanese caption on the first existing caption plate. Accessible region/list supports scrolling and arbitrary application photo arrays; initial preview shows exactly the two scoped originals.

Native Meiryo with existing licensed Noto Sans JP fallback; role sizes follow the source instruction. Source/original/Image Gen histories remain separate from rendered QA and live verification. No pixel identity, physical-device/human acceptance, service integration or Maker registration is claimed.
