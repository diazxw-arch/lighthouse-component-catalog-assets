# LH01-0006 · 現在地と地図の位置指定

Reusable React component: `LocationChoice`.

Separate onCurrentLocation/onMapSelect callbacks. Busy disables actions and exposes a visible status; errors are application-owned. The preview never requests location permission or pretends to obtain coordinates.

Initial preview contains only the requested component. App services, persistence, authentication and data access remain application-owned. No native/device or human acceptance is claimed.

Design: original reference governs icon anatomy and fine geometry, with selected Image Gen v2 governing the reviewed Japanese rendition. Meiryo with licensed Noto Sans JP fallback; preserve authored blue location shortcuts, green history action and selected histogram, and neutral quantity controls. Shared libraries/fonts remain under their original Apache/OFL licenses.

Verification and exact release evidence are recorded in the per-item QA and Owner A acceptance ledger. Shared FigCraft cleanup is deferred until all dependent siblings are replaced and exclusive native editing is supported.
