# LH05-0021 · 文字サイズの二段階操作

このカードは実際のReactコンポーネントです。画像ではありません。
小・大で文章の文字サイズを変更できます。紫の外枠は目録上の実装済みの印です。

実装元: `src/components/catalog/TextSizeControl.tsx`
スタイル: `src/components/catalog/text-size-control.css`

```tsx
import { useState } from 'react';
import { TextSizeControl } from '@/components/catalog/TextSizeControl';

function Reader() {
  const [fontSize, setFontSize] = useState(18);
  return <>
    <TextSizeControl value={fontSize} onValueChange={setFontSize} controls="passage" />
    <p id="passage" style={{ fontSize }}>ここに本文を表示します。</p>
  </>;
}
```

`min`（既定14）、`max`（24）、`step`（2）、`disabled`、`className`を設定できます。
値・保存・データ取得は呼び出し側が管理します。複数のインスタンスは独立しています。
ホバー、押下、キーボードフォーカス、上限・下限の無効状態があります。
動きを減らすOS設定ではトランジションと押下の縮小を停止します。
この見本はブラウザー内で動作し、アカウント・教会データを取得しません。

元の画像・生成履歴は別に保管しています。実装したことは、画像との99%一致や
所有者の最終受入を数値で証明するものではありません。
