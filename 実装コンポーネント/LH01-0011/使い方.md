# LH01-0011 · 設備の複数選択チップ

Reusable React component: `AmenityChips`.

selectedIds/onValueChange control five independent amenities; native buttons expose aria-pressed, disabled state, pointer/keyboard feedback and stable IDs. Only wifi is initially selected in the reference preview.

Design: original source controls fine geometry; selected Image Gen v2 supplies the reviewed Japanese rendition. Meiryo/Noto Sans JP, authored green selection/actions, white surfaces, neutral focus. Initial presentation is only the requested component.

The five equipment glyphs use their original screenshot crop pixels as bounded luminance masks, removing only the light source-card background before applying the semantic icon color. The original bytes/hash/crop bounds are inspectable in original-amenities.svg and ORIGINAL-DISCOVERY-ASSETS.md; no replacement glyph paths are drawn.

No human/pixel-identity certification, backend persistence, physical-device acceptance or Maker integration is claimed. QA, catalog release, exact deployment and deferred native cleanup are separate acceptance gates.
