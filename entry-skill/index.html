既存の目録件数と、このスキルの計測済み完了数は別です。初版の検証用データは実際の新規登録に数えていません。過去のチャットの経過時間から作業速度を推定していません。

1部品を登録する手順

  1. 出典と構造を調べる。保存済みのMobbin参照を優先し、許可された範囲で新たに調査。全分野の既存部品と比較し、状態・文言・色だけの違いを除外します。
  2. 原画像を保存する。URL・アプリ・画面ID・元の寸法・ハッシュと、部品の正確な範囲を残します。
  3. 実際の部品画像を切り出して見る。原画像を変えずにPNGを保存。画面全体や隣の部品を含めず、切り出した実ファイルの全辺と内容を確認します。
  4. 用途と品質を確かめて登録する。教会アプリでの使い方と構造上の違いを記録。既存形式と履歴を保ち、保存後に読み戻します。

参照登録・画像切り出し・ネイティブ実装・ビルド・忠実度審査・公開は、それぞれ別の確認です。

30部品ごとに、時間と品質で手順を見直す

異なる部品の完了が30件に達すると、次のバッチへ進む前に審査します。再試行・切り直し・重複・無効な登録は件数を増やしません。版は 1.0 → 1.1 → 1.2 と0.1ずつ進みます。

既存の作業から取り込んだ修正

新しい画面IDでも、同じ部品構造なら重複

全分野の近い部品を目視で比較します。スクロール位置や開閉状態の差だけでは新しい部品にしません。

座標やファイル名だけでは切り出し完了にならない

実ファイルの存在・寸法・ハッシュ・元の画素との一致を検証し、その画像自体を確認します。

検索でエラーが出ても、検証済みの保存参照は再利用できる

新しいアクセスの失敗と、以前保存した正当な証拠を分けて扱います。認証や利用制限の回避は行いません。

目録の形式と、3つの集計フラグを保持

実際の各分野のcatalog.jsonだけを読みます。バックアップや参照リストを件数に含めず、既存の制作・検証履歴を変更しません。
