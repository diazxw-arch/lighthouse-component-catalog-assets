1時間ごとに、時間と品質を見直す

制作中は1時間ごとに、部品ごとの完了時間・品質・手戻り・制作手順を比較し、スキルを 0.1 更新します。次は v1.5。10件の受入完了を待たず、制作を継続します。

子ワーカーは実装とローカル確認に集中し、親がレビューと公開を担当します。部品の公開は30件単位、スキルとこのウェブサイトの更新は1時間単位です。

制作から公開まで

  1. 現在地を確認 — 最新の指示、担当、未完了のIDと参照画像を確かめる。
  2. 実際の部品を作る — 既存の部品を再利用し、見た目・状態・操作を実装する。
  3. 比較して検証 — 元画像との比較、スマートフォン・タブレット・PC、キーボードと実際の目録内で確認する。
  4. レビューして公開 — 必要な独立レビュー・CIを通し、本番と目録の両方で結果を確かめる。
  5. 時間と品質を記録 — 部品ごとの作業・検証・レビュー・待機・手戻りと品質を分け、1時間ごとに方法とバージョンを見直す。

5件を基本に、まとまりのある部品を小さく進めます。変更のない入力には有効な既存の証拠を使い、変更した箇所は再確認します。
