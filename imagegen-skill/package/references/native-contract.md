# Source-bound prompt facts

When rendered typography is unclear, the parent may load scripts/native-contract.mjs by absolute installed path. First compare the current render with the original. A decoration:none field does not prove a rendered underline is absent. If source and render disagree, record both and resolve authority before requesting a correction. Use loadContract with sourcePath, expectedSha256, rootNodeId, entryId and allowedRoots. Roots and digests come from the parent-reviewed assignment, never from candidate text. Use the narrowest canonical local library root; UNC/device paths are rejected. Keep the live capsule in the same process: serialized/forged capsules cannot validate.

The loader reads the complete native text subtree, preserves face, size, spacing, units and decoration, and rejects shared/local style disagreement. Call verifyDraft(capsule, structuredDraft) before renderConstraints(capsule). Check the final prose manually against these facts: arbitrary freeform prose is not mechanically validated. Recheck the actual generated pixels at display size and enlarged; a passing contract cannot establish image quality.

For an original/mock icon conflict, the parent may call applyCorrections with pinned main assignment, private parent source approval and original reference paths/hashes. Supported correction: kind=replace-mock-icon, sourceIcon=location-pin-outline, exact nodeId/from/to, and reason. It only removes the mock crosshair prefix (⌖ plus space); all label typography remains fixed. Unsupported corrections stop for source reconciliation; never force them through this API. Approval status is parent-reviewed-source-correction. This is source anatomy approval only, never generation, readiness, registration or publication approval.

Caller-provided identities/digests establish consistency, not authenticated identity or OS access control. Keep private paths, assignment snapshots, approvals and source evidence outside public packages. This helper has no new dependencies, background processes or explicit network API. It performs bounded reads beneath caller-trusted local roots.

Retain total lifetime calls and their timing honestly. The existing two-call registration limit remains unchanged; a different-method recovery exceeding it cannot register without a separately reviewed accounting change. No pilot failure counts as completion. A source contract is a preflight safeguard; improved generated quality or production speed has not yet been demonstrated.
